

# Pokedex CLI

A command-line Pokedex built with TypeScript. This tool interacts with the [PokéAPI](https://pokeapi.co/) to fetch and display information about various Pokémon, including their stats, types, and more.

## Features

- Fetch real-time Pokémon data.
- Interactive REPL (Read-Eval-Print Loop) interface.
- Local caching for improved performance.

## Prerequisites

- **Node.js**: v22.15.0 (managed via `nvm` recommended)
- **Go**: (If using the Boot.dev CLI for testing)
